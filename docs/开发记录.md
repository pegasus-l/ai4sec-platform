## 2026-07-16 — 纠正“数据源获取”误解：当前只做本地原始数据导入

### 背景

用户指出当前阶段已经说过“先不做数据源获取”，但代码里出现了 `SourceConnector`、`raw_pipeline`、`arxiv/github/rss` 等名称，容易误解为已经在做联网采集。

### 纠偏结论

当前阶段不做联网数据源获取。平台只读取旧流程已经落盘的本地原始 JSON 文件，然后走新平台自己的处理链路：

```text
本地 raw JSON
→ raw_artifacts
→ normalized_items
→ dedupe / evidence
→ domain_items
→ model_calls / quality_audits / human_queue
→ API / 前端页面
```

### 已完成调整

- 在 `configs/app.yaml` 增加 `live_source_fetch_enabled: false`。
- 在 `Settings` 增加 `live_source_fetch_enabled` 配置项。
- `JsonFileConnector` 改为本地原始文件适配器语义：`source_type=local_raw_file_adapter`。
- `JsonFileConnector.fetch()` 遇到 HTTP/HTTPS 路径会直接返回 `live_source_fetch_disabled`，不会联网。
- `SourceRegistry.list()` 增加 `mode=local_raw_file_only`，API/调试时可以看到当前边界。
- 为三条已实现 pipeline 增加更准确的别名：
  - `news.ai_for_sec_local_raw_import`
  - `threats.huawei_local_raw_import`
  - `vulnerabilities.material_local_raw_import`
- 保留旧 `*_raw_pipeline` 名称作为兼容入口，但 README 优先使用 `*_local_raw_import`。

### 后续命名原则
