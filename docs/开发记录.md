# 开发记录

## 2026-07-16 — 第一阶段平台骨架与旧数据展示闭环

### 目标

按 `docs/平台总体架构设计.md` 的第一阶段修订方案，先不做采集、模型重跑或复现执行，而是用现有旧数据搭出可运行的 AI4SEC 平台后端。

### 已完成

- 初始化新目录 Git 仓库，并确保 `.env` 被 `.gitignore` 忽略。
- 新增平台主设计文档和新目录 `AGENTS.md`。
- 建立 Python 包结构：`src/ai4sec_platform/`。
- 使用标准库 `sqlite3` 实现第一阶段数据库，避免当前环境缺少 SQLAlchemy 阻塞开发。
- 实现压缩表结构：`domain_items`、`evidence_items`、`pipeline_runs`、`task_runs`、`artifacts`、`data_sources`、`quality_audits`、`human_queue_items`。
- 实现旧数据导入器：AI-for-Sec、华为目标、漏洞素材。
- 实现 FastAPI 展示接口，覆盖四个业务域和统一运营入口。
- 导入旧数据样例并完成 API smoke 验证。

### 关键决策

- 第一阶段用旧数据导入支撑页面展示，不实现真实采集 connector。
- 第一阶段不触发模型、不执行复现 runner。
- 因当前环境没有 SQLAlchemy，先用 `sqlite3` 实现稳定闭环；后续可按主设计迁移到 SQLAlchemy / SQLModel。
- 前端 demo 暂不修改，后端接口优先对齐 demo 的四域和统一运营结构。
